## Privacy Policy

1. **Data we collect.** The application does not collect, store or process personal data of any
   third-party users. It is not offered as a service to the public.
2. **Google / YouTube account access.** The application uses OAuth 2.0 solely to access the
   owner's own YouTube channel for uploading videos, setting thumbnails and updating video
   metadata. OAuth credentials (refresh token) are stored locally on the owner's own device and
   are never transmitted to any third party.
3. **No sharing.** No data obtained through Google APIs is sold, shared or transferred to any
   third party, except as necessary to provide the upload functionality to YouTube itself.
4. **Storage.** Uploaded videos and their metadata are stored on YouTube according to YouTube's
   own policies. No separate copy of user data is retained by this application.
5. **YouTube API Services.** By using this application you agree to be bound by the
   [YouTube Terms of Service](https://www.youtube.com/t/terms). Google's privacy practices are
   described in the [Google Privacy Policy](https://policies.google.com/privacy).
6. **Revoking access.** The owner may revoke this application's access at any time via
   [Google Account permissions](https://myaccount.google.com/permissions).
7. **Contact.** For any privacy question, contact the owner via
   [GitHub](https://github.com/mukeshrawat1129515-prog).
